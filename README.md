## 📖 项目简介

这是一个面向**学生、研究者和写作者**的本地查重工具箱,围绕一个核心目标构建:**在保护隐私的前提下,尽可能全面地发现文本重复**。

它由三部分组成:

- **网页版**(主入口):拖拽上传,浏览器可视化查看结果,支持三种检测模式;
- **检测核心**:`check_plagiarism.py` 提供本地比对、引用识别、知网式指标、报告生成,可独立命令行调用;
- **AI Agent 技能**:遵循 [Agent Skills](https://agentskills.io) 开放规范(SKILL.md),让 ZCode、Claude Code 等支持技能的 AI 编程助手能够自动触发完整查重流程。

与在线查重网站不同,它**不需要注册、不需要付费、不会把你的论文上传到任何私有服务器**;与纯本地工具不同,它可以通过开放学术数据源主动检索文献出处。

## ✨ 功能总览

### 三种检测模式

| 模式 | 工作方式 | 联网 | 适用场景 |
|---|---|---|---|
| 🌐 **在线检索查重** | 自动切句 → 逐句到多个开放学术库与搜索引擎检索出处 → 抓取原文**逐字核验 + 模糊匹配** | ✅ | 检查论文是否与公开文献/网络内容重合 |
| 📁 **与本地文献比对** | 与你提供的参考文献、往稿、整个文件夹的语料做 k 连续词元窗口比对 | ❌ | 投稿前与引文原文核对、自我查重(新稿 vs 旧稿) |
| 🔍 **AIGC 疑似分析** | 五项风格信号加权评分(0-100),逐句橙色/黄色标注 | ❌ | 自查写作风格是否"AI 味"过重 |

### 知网式指标体系(v2.0)

报告输出与知网口径一致的三层指标,而不是一个笼统的百分比:

| 指标 | 含义 |
|---|---|
| **总文字复制比** | 论文中与任一参照来源逐字重合的文字占比(含引用与文献列表) |
| **去除引用文献后复制比** | 剔除"合理引用"与"参考文献列表"后的复制比,**衡量抄袭程度的主指标** |
| **引用率** | 被识别为合理引用的部分占比 |
| **分章节复制比** | 按"第 X 章 / 1.1 / 摘要"等标题行自动划分章节,逐章给出复制比并降序排列 |

### 引用识别(v2.0)

重复片段会被自动归类为三种性质之一,并分别统计:

- **〔合理引用〕**:片段带有 `[1]`、`(2021)` 之类的引文标记,或整体位于引号内——通常是你正确标注了出处的引用;
- **〔文献列表〕**:与文末参考文献条目重合的部分——列出文献本身不算抄袭正文;
- **〔疑似抄袭〕**:其余的逐字重合——这才是需要重点对待的部分。

### 模糊匹配(改写检测,v2.0)

在线检索时,对候选文献摘要做**句级 3-gram 相似度**比对(阈值 35%):轻度改写(同义替换、连接词调整、语序微调)会被单独标记为"疑似改写"并附上候选来源与原句,供人工确认。模糊匹配结果**不计入复制比**,避免误伤——这是它与逐字匹配并行的独立安全网。

### 数据源

| 数据源 | 规模 / 内容 | 渠道 | 核验方式 |
|---|---|---|---|
| [OpenAlex](https://openalex.org) | 约 2.5 亿篇文献的题录与摘要 | API | 候选文摘逐字核验 + 模糊匹配 |
| [Europe PMC](https://europepmc.org) | 开放获取全文 + 数千万摘要(偏生物医学) | API | 前缀短语 / 特征词双查询 + 逐字核验 |
| [arXiv](https://arxiv.org) | 约 240 万篇预印本(英文为主) | API | 逐字核验 + 模糊匹配 |
| 搜索引擎 | 360 / 搜狗(中文)、Bing(英文) | 网页解析 | 候选页抓取正文逐字核验 |

所有在线结果都经过**本地逐字(或模糊)核验**后才计入,搜索引擎的松散匹配不会造成误报。

## 🚀 快速开始

**环境要求**:Python 3.8+(仅标准库;读取 PDF 需额外 `pip install pypdf`)。

### 网页版

```bash
python scripts/webapp.py          # 自动打开浏览器,默认 http://127.0.0.1:8765
```

Windows 可直接双击 [`start_web.bat`](start_web.bat);macOS / Linux 运行 `bash start_web.sh`。
端口被占用时程序会明确提示,可用 `--port 8766` 更换;`--no-open` 禁止自动开浏览器。

### 命令行版

```bash
python scripts/check_plagiarism.py --paper 论文.docx --refs 文献目录/ 旧稿.txt \
    --out 查重报告.md --html 查重报告.html --json 查重结果.json
```

| 参数 | 说明 |
|---|---|
| `--paper` | 待检论文(.docx / .pdf / .txt / .md) |
| `--refs` | 参照来源:文件或目录,可多个(目录会递归扫描) |
| `--k` | 判定窗口:连续多少词元相同算重复(默认自动:中文 13 / 英文 6) |
| `--min-run` | 片段最小长度,过滤零碎短片段(默认等于 k) |
| `--ctx` | 片段摘录的上下文词元数(默认 6) |
| `--out / --html / --json` | 分别输出 Markdown / HTML 高亮 / JSON 三种报告 |
| `--max-runs` | 报告明细最多列出的片段数(默认 200) |

### 安装为 AI Agent 技能

遵循 **Agent Skills 开放规范**,任何支持 SKILL.md 的 AI 编程工具都能使用:

1. `git clone` 本仓库,或 **Code → Download ZIP**(⚠️ ZIP 解压后需把文件夹重命名为 `paper-plagiarism-check`);
2. 放入技能目录:ZCode → `~/.agents/skills/`;Claude Code → `~/.claude/skills/`;其他工具查阅其 skills 目录约定;
3. 新开会话,直接说"帮我给这篇论文查重"即可自动触发完整流程。

## 📊 输出报告说明

每次检测生成三种形态的报告:

- **网页可视化**:重复/引用片段黄色高亮、逐句 AIGC 标注、章节表格;
- **Markdown 报告**:三大指标 + 章节表 + 片段明细(论文/来源双方原文对照)+ 局限说明;
- **HTML 报告**:带样式的完整报告,可下载存档;
- **JSON 报告**:结构化数据(片段坐标、来源、指标),便于二次处理。

报告中的每处重复片段都包含:**性质标签**(疑似抄袭/合理引用/文献列表)、**长度与段落定位**、**来源文献(标题/链接/期刊)**、**双方原文对照**。

## 🔬 检测原理

- **本地比对**:中文逐字、英文按词切分为"词元"序列,归一化(忽略大小写/全半角/空白/标点)后,凡与参照来源存在 k 个连续相同词元即计为重复,并合并为最大片段——这是业界通行的"连续 13 字判重"思路的本地实现;
- **引用识别**:自动抽取文末参考文献列表建立词元集合,结合 `[n]` 标记与引号检测,把重复内容分为"引用 / 文献列表 / 疑似抄袭"三类;
- **在线检索**:切句 → 多源关键词/短语检索候选 → 抓取原文(自动跟踪搜索引擎中转页)→ 本地逐字核验,只把核验通过的计入;检索请求自动限速、429 自动退避、连续失败自动停用该来源并明确警告;
- **模糊匹配**:候选文摘与论文句子做 3-gram Jaccard 相似度(实测:轻度改写 0.5-0.85,同领域无关句 ≤0.2,阈值 0.35),单独报告;
- **AIGC 疑似度**:句长均匀度(burstiness)、模板短语密度("随着…的快速发展"等 20+ 组中英模板)、连接词开头句占比、模糊限定词密度、顿号列举密度五项信号加权。

## ❓ 常见问题

**Q: 结果和知网一样吗?**
不一样,也不应一样。知网的准确率来自其独家授权的亿级文献库;本工具的数据源是开放学术库与搜索引擎,覆盖范围不同。它输出的是"与开放数据源/自选文献的重合度",检测**维度**对齐知网(连续字符匹配、引用分离、三大指标、分章节),但**数值没有对应关系**。

**Q: 能检测改写吗?**
逐字重复、小句级重复:能。轻度改写(换几个词、调整语序):在线渠道的模糊匹配会单独提示"疑似改写",需人工确认。深层语义改写、中英互译:检不出,这类需要语义模型。

**Q: 我的论文数据安全吗?**
本地比对与 AIGC 分析完全离线。在线模式只把**句子片段**发送给公开学术 API 与搜索引擎用于检索,不会上传整篇文档到任何服务器;服务默认只监听本机 127.0.0.1。

**Q: 支持哪些文件格式?**
`.docx / .txt / .md` 开箱即用(自动识别 UTF-8/GBK/Big5/UTF-16 编码);`.pdf` 需要 `pip install pypdf`(扫描版 PDF 无文字层,无法检测)。

**Q: 误报了怎么办?**
每个片段都附来源与双方原文对照,请逐条人工确认;通用套话造成的零碎片段可用 `--min-run` 提高阈值,或勾选/调整判定窗口 `--k`。

## ⚠️ 如实说明

- **数据库覆盖无法等同知网**:知网的检测能力来自独家授权的亿级文献库(学位论文、期刊、大学生论文联合比对库等),任何开源工具都无法获取同等数据。本工具检测**维度**对齐知网,数值上与知网/Turnitin **没有对应关系**。
- 同义改写、语序调整、中英互译后的雷同:轻度改写由模糊匹配提示,深层语义改写检不出。
- 模糊匹配是统计启发式,存在漏检与误报,结果需人工确认。
- AIGC 疑似度不构成"AI 写作"的证明:模板化的人写文章会得分,朴素的 AI 文本可能低分。
- 在线检索受各数据源限流策略影响,请求自动退避、超限自动停用该来源并在报告中明确提示"结果不完整"。
